# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately from the repository's **Security** tab by selecting [Report a vulnerability](https://github.com/hyeonsangjeon/im-not-ai-en/security/advisories/new). Do not open a public issue for an undisclosed vulnerability.

Do not include real workplace text, credentials, customer data, proprietary source code, or personal information. Use the smallest synthetic reproduction that demonstrates the issue.
