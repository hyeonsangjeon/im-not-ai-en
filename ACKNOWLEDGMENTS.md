# Acknowledgments

The English copyediting design in this project was informed by public, MIT-licensed projects including:

- the [retext ecosystem](https://github.com/retextjs/retext), especially its narrowly scoped diagnostics for [indefinite articles](https://github.com/retextjs/retext-indefinite-article), [contractions](https://github.com/retextjs/retext-contractions), [repeated words](https://github.com/retextjs/retext-repeated-words), and [spelling](https://github.com/retextjs/retext-spell), for contextual exceptions and structured language checks;
- [Vale](https://github.com/vale-cli/vale) and its [Microsoft](https://github.com/vale-cli/Microsoft) and [Google](https://github.com/vale-cli/Google) style packages, for markup-aware scoping, configurable house-style rules, severity levels, and fixture-based validation;
- [write-good](https://github.com/btford/write-good), for independently selectable checks and exception handling; and
- [textlint](https://github.com/textlint/textlint), for separating syntax-aware parsing, diagnostics, and fixes.

This repository does not vendor or depend on those projects. No source code, regular-expression rule tables, word or exception lists, documentation text, test cases, or model weights from them are included. The editorial instructions and synthetic fixtures in this repository were written for this project. These references document design research; they do not imply endorsement, compatibility, or comprehensive grammar coverage.
